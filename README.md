# Smarter Angular mit WebGPU & Transformers.js

[JavaScript & Angular Days Berlin 2026](https://javascript-days.de/angular/smarter-angular-mit-transformersjs-prompt-api/), 13. Oktober 2026, 14:00–17:30 Uhr

Trainer: Christian Liebel ([@christianliebel](https://x.com/christianliebel))

---

In diesem praxisorientierten Workshop lernst du, wie du deine Angular-basierten Apps mit modernen Generative-AI-Bibliotheken wie Transformers.js smarter machst – und das offlinefähig und kostenlos.

Anhand der Integration eines kontextsensitiven Chatbots in eine Todo-App erfährst du, wie du KI-Modelle im Browser betreiben und mittels WebAssembly, WebGPU oder WebNN performant lokal auf deinem Endgerät ausführen kannst.

Du erhältst einen Überblick über KI-Architekturen und lernst Best Practices für Prompt-Engineering kennen. Und du entwickelst aktiv mit, wenn du willst.

1. Vorstellung des Demo Use Cases
1. Grundlagen generativer KI
1. Vor- und Nachteile lokaler KI-Modelle
1. Übersicht und Verwendung von Transformers.js
1. Alternative Ansätze

## Installationsanweisungen

Wenn Sie mitentwickeln möchten, bringen Sie bitte ein leistungsfähiges Gerät mit Windows oder macOS, eine aktuelle Version von Chrome, Node.js, einen Editor Ihrer Wahl und mindestens 20 GB freien Festplattenspeicher mit.

Idealerweise ist dies Ihr privates Gerät, da Gruppenrichtlinien oder Unternehmensproxys oft Probleme verursachen.

Nachdem Sie das Repository geklont haben, führen Sie bitte die folgenden Befehle in der Kommandozeile aus:

```sh
cd angular-days-2026-fall-transformers
npm i
```
